AI Email Summarizer & Task Generator

Live & Deployed

Automated Email Intelligence Pipeline

A fully automated system that monitors a Gmail inbox, uses Claude AI to summarize incoming emails, forwards clean summaries to the right person, and automatically creates tasks in Asana — all without any manual input. Deployed live on Railway and running 24/7.

What it does

  • Monitors inbox for unread emails every 60 seconds
  • Summarizes email content using Claude API
  • Auto-creates tasks in Asana with AI-generated descriptions
  • Forwards clean summaries to the right recipient
  • Filters untrusted senders for security
  • Runs 24/7 on a live cloud server

Tech Stack

  • Python — core automation logic
  • Gmail API — inbox monitoring & sending
  • Anthropic Claude API — AI summarization
  • Asana API — task creation
  • Railway — cloud deployment
  • GitHub — version control & CI/CD
